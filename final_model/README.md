# 固定最终模型

`model.pt`是SimpleCNN第52轮的state_dict，426,764字节（约417KiB），随仓库和ZIP提供。

第1—45轮学习率0.03，第46—52轮0.01。选择依据是验证准确率最高，平分取同轮较低验证损失；测试结果未参与选择。完整配置与类别映射见`config.json`，来源和哈希见`provenance.json`。逐轮完整检查点仅保留在原工作目录，不在公开包中。

验证准确率91.66%，损失0.260076；既有官方测试准确率91.65%，损失0.271073，Shirt召回率75.60%。两个指标文件来自同一份权重。此次整理没有重新评估测试集。
